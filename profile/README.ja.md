# 多宝（タタカラ）

多宝（タタカラ、英語名 Ishtar Gate）は、私が個人で作った小さなツールを公開するときの名義です。どれも空いた時間に個人で開発しています。すべての機能を無料でお使いいただけます（今後も変わりません）。

[作者のウェブサイト](https://re-jeunesse.org/)
